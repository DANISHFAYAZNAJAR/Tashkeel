# Tashkeel — Real-Time Mosque Translation

A real-time AI-powered translation system for mosques. The Imam speaks through one microphone — worshippers hear the meaning in their own language through a discreet wireless earpiece.

## The Problem
Nearly 2 billion Muslims attend prayers worldwide. Over 80% don't speak Arabic. Sermons, Quranic recitations, and lectures remain inaccessible to the majority of the global Muslim community.

## The Solution
Tashkeel bridges that gap using AI — one mic, many earpieces, under 1 second latency, 100+ languages supported.

## How It Works
1. Imam speaks through a microphone
2. AI translates speech in real time (<1 second)
3. Translation broadcasts wirelessly inside the mosque
4. Worshippers hear it in their language via earpiece or mobile app
